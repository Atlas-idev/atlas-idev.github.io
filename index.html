2026iOS · Android · Web

ParkMe

Réservation de places de parking à Madagascar : un seul code Expo pour iOS, Android et le web, une API temps réel et trois espaces (membre, gardien, administration).

  • 3plateformes, un seul code
  • 14villes dans la démo
  • 290contrôles automatisés
  • Carte aux couleurs de ParkMe (MapLibre, OpenStreetMap), itinéraire intégré et places libres en direct.
  • Réservation en 4 étapes avec plan des places, Mobile Money simulé (MVola, Orange Money, Airtel) et ticket QR code.
  • Scanner QR pour les gardiens, tableau de bord administrateur : revenus, occupation, réservations.
  • PostgreSQL empêche toute double réservation ; intégration continue avec GitHub Actions.
  • Expo
  • React Native
  • TypeScript
  • Node.js
  • PostgreSQL
  • Prisma
  • Socket.IO
